WexideVisuals — автоматическая сборка JAR через GitHub

1. Войди на https://github.com и создай новый репозиторий (New repository).
2. Выбери Public или Private, нажми Create repository.
3. Нажми uploading an existing file / Add file → Upload files.
4. ЗАГРУЗИ СОДЕРЖИМОЕ распакованного ZIP, включая скрытую папку .github (не сам ZIP).
   Если Windows не показывает .github, включи «Скрытые элементы» в Проводнике.
5. Нажми Commit changes.
6. Перейди во вкладку Actions → Build WexideVisuals JAR → Run workflow.
   Сборка также может запуститься автоматически после загрузки.
7. Дождись зелёной галочки, открой запуск, внизу скачай Artifacts → WexideVisuals-1.21.4.
8. Распакуй скачанный ZIP. Положи wexidevisuals-0.1.0.jar (не sources) в .minecraft/mods.
9. Установи Fabric Loader и Fabric API для Minecraft 1.21.4.

Внимание: исходный мод не проверен реальной сборкой. При ошибке в Actions пришли лог — исправлю.
